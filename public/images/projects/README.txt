## Tips for Great Screenshots

1. **Use real or realistic data** - No lorem ipsum
2. **Clean browser window** - Remove bookmarks bar, extensions
3. **Proper aspect ratio** - Crop to 1200x800px exactly
4. **High contrast** - Ensure text is readable
5. **Feature the core functionality** - Show what makes each project unique
6. **Consistent style** - Try to match the nature theme colors where possible

## How to Add

1. Take or create your screenshots
2. Resize to 1200x800px
3. Save with exact filenames listed above
4. Add to this directory
5. Refresh your portfolio - images will load automatically
