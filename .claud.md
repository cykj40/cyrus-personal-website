# Claude Code Instructions

This is Cyrus Khiabani's personal portfolio website.

## Tech Stack
- React 19 + TypeScript
- TanStack Router + TanStack Query
- Tailwind CSS + Framer Motion
- Vite build tool
- Vercel deployment

## Design Theme: "Grounded Tech"
- Nature-inspired colors: Forest green (#2D5016), Mountain blue (#4A7C9C), Sunrise orange (#D97706)
- Clean, professional, authentic
- Represents: nature-lover + technical excellence

## Project Structure
- `/src/components/layout/` - Navbar, Footer
- `/src/components/sections/` - Hero, About, Projects, Services, Contact
- `/src/components/ui/` - Reusable UI components
- `/src/data/` - Project and skills data
- `/src/routes/` - TanStack Router routes
- `/api/` - Vercel serverless functions

## Key Files
- `src/data/projects.ts` - Portfolio projects
- `src/data/skills.ts` - Tech stack
- `src/routes/index.tsx` - Home page (single-page app)
- `api/contact.ts` - Contact form handler

## Documentation
- All phase notes, audit reports, and other session documentation go in `project-notebook/`, not the repo root. Do not create new `.md` files at the repo root except `README.md`, `LICENSE`, and existing agent-instruction files (`AGENTS.md`, `.claud.md`).

## Important Notes
- This is a single-page application with smooth scrolling
- All sections are on one page (Hero, About, Projects, Services, Contact)
- Nature theme should be maintained in all additions
- Type safety is critical - all code must be properly typed
- Follow existing code style and patterns

## When Adding Features
- Keep the nature-inspired design theme
- Maintain type safety with TypeScript
- Follow the existing component structure
- Use Tailwind CSS for styling
- Add Framer Motion for animations where appropriate

## Testing
- Run `pnpm dev` to test locally
- Check mobile responsiveness
- Verify smooth scrolling between sections
- Test contact form validation

## Deployment
- Push to GitHub to trigger Vercel deployment
- Or use `pnpm deploy` for manual deployment
